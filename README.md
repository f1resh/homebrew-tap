# F1resh Tap

## How do I install these formulae?

`brew install f1resh/tap/<formula>`

Or `brew tap f1resh/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "f1resh/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
